# 🛍️ Smart Shop - Mini E-Commerce Website

Smart Shop is a simple and modern single-page e-commerce web application built using **HTML, CSS, and JavaScript** without any frameworks. It demonstrates core front-end concepts like DOM manipulation, localStorage, and dynamic UI updates.

---

## 🚀 Features

- 🛒 Product listing with icons
- 🔍 Live search/filter system
- ➕ Add to cart functionality
- ❌ Remove items from cart
- 💰 Automatic total calculation
- 💾 Cart saved using localStorage
- 📱 Fully responsive design

---

## 🧑‍💻 Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla)
